# PIRBN

“PIRBN-acoustic” refers to the solution of the 2D acoustic scattering problem governed by the Helmholtz equation using the Physics-Informed Radial Basis Network (PIRBN) architecture, incorporating three key enhancements: a wavelength-based distribution of collocation points and radial basis function (RBF) centers, a mixed residual-based adaptive distribution (Mixed-RAD) strategy, and a Fourier series Dirichlet-to-Neumann (DtN) boundary condition implemented via a multi-circle weighted approach.
